# Security policy

## Supported version

Security fixes target the current `master` branch. Older releases may not receive backports.

## Report a vulnerability privately

Use **Report a vulnerability** on this repository's [GitHub Security Advisories page](https://github.com/Shreshtgaming606/OmniCore-Discord-Bot/security/advisories). Private vulnerability reporting is enabled for this repository. If the form is unavailable, contact the maintainers privately through their GitHub profiles and ask for a private channel. Do not open a public issue for an unpatched vulnerability, and do not paste credentials or private user data into a public discussion.

Include affected version or commit, a clear reproduction, impact, and a safe way to verify the fix. Avoid testing against servers or accounts you do not control. Maintainers will acknowledge the report and coordinate a fix and disclosure timing through the private channel.

If you exposed your own token or provider key, revoke and replace it at its issuer immediately. Removing a value from the latest commit does not remove it from prior Git history or copies.
