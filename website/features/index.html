What OmniCore does

Built around real server work.

Moderation controls, practical utilities, and an AI assistant that requires team approval.

Moderation with direct controls.

Discord permission checks apply to moderation commands, and the bot needs matching permissions and role position.

Act on the situation

Kick or ban members, set or remove timeouts, and remove messages with a channel and optional member filter.

Browse moderation commands↗

Manage access

Lock creates a role and applies a channel overwrite. Unlock removes the role and its saved channel record.

An assistant with a clear boundary.

Approved servers can use the existing locally hosted assistant. A server owner can also connect their own OpenAI, Anthropic, or Gemini API key through Discord OAuth and an HTTPS pairing page; authorized members can then use /ask or mention OmniCore under server limits. Provider charges go directly to the provider.

The assistant sends recent stored conversation context to the configured Ollama endpoint. It can search Wikipedia. A separate AutoMod system reviews selected server messages. The first confirmed violation gets a public reply that mentions the member and states the reason; another confirmed violation within 24 hours may trigger a temporary timeout. Server owners and protected staff can be warned but are not automatically timed out. The server owner is notified under their settings. The server owner can also ask OmniCore to mute one specified member for up to two days by mentioning both the bot and member with a duration, such as @OmniCore mute @member for 10m.

Administrators can set a server prompt and run /delete_memory to clear the server's stored AI history.
