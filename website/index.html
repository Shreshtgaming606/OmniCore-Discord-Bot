Controlled AI

Bring the assistant in when your server is ready.

In approved servers, OmniCore responds to mentions and replies using a configured Ollama model. Server admins can set a custom prompt and clear saved conversation history.

AI replies can use Wikipedia lookup and a timeout tool. Review the bot's permissions before enabling AI.
