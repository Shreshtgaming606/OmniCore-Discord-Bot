Fix a problem

Check the common causes before contacting the bot team.

A command is missing

Type / and select OmniCore. Check whether the command is for a server or a DM and whether your Discord permissions allow it. Newly registered global commands can take time to appear; close and reopen the command picker.

Browse the command reference for names and permissions.

Back to top ↑

AI says it is unavailable

Ask the server owner to run /ai status. The server needs bot-owner approval for local AI or a provider connected through /ai setup. Channel or role restrictions, daily limits, an unavailable model, and provider errors can also block a request.

Back to top ↑

The bot did not see my image

Attach the image to your own question or reply directly to the exact image message. OmniCore never searches previous unrelated messages. Check the image format and count, and ask the owner whether the selected model supports vision.

If /imagine fails, the local image model, queue, memory, or host disk guard may be unavailable. This installation requires at least 10 GiB of free internal disk space for image generation.

Back to top ↑

AutoMod warned but did not time out

The first confirmed violation is a warning. A later confirmed violation within 24 hours may time out an eligible member only when timeouts are enabled. OmniCore needs Moderate Members permission and a higher role than the target. Protected staff and server owners are not automatically timed out. Ask the owner to check /automod status.

Back to top ↑

My DM is still waiting for approval

Your first written DM creates a request for OmniCore bot owners. Use /dmaccess status to check it. A Discord server owner cannot approve private text access unless they are also an OmniCore bot owner. Do not resend your first message expecting an AI response before approval.

Contact support

Include the command name, server, approximate time, and what you expected. Do not include tokens, API keys, or private message content in a public report.
