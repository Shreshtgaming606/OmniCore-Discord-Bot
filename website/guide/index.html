Start here

Get started in three steps

OmniCore has tools anyone can use, moderation commands that require Discord permissions, and settings reserved for the actual server owner. OmniCore bot owners are a separate group: they approve local AI and private DM requests.

  1. Add OmniCoreUse the installation page if the bot is not in your server. Give it only the permissions needed for the features you plan to use.
  2. Find a commandType / in a Discord text channel and choose OmniCore, or run /help. Discord shows the command options before you send it.
  3. Check AI accessLocal chat and image generation require approval from an OmniCore bot owner. A server owner can instead connect their own OpenAI, Anthropic, or Gemini account with /ai setup. AutoMod works independently of chat approval.
How to read examples

In /time member:@Alex duration:10m, the text before each colon is an option name. Discord supplies the option fields; select the real member, channel, or role in its picker. Examples here use placeholder names.

Path 01 / Server owner

Configure your server

The server owner is the Discord account that owns the server. Administrator permission alone does not grant access to OmniCore's owner-only /ai or /automod controls.

1. Review AutoMod

AutoMod is enabled by default. Run /automod status to see the current policy. A first confirmed violation produces a warning; another confirmed violation by the same member within 24 hours can produce a timeout when timeouts are enabled and Discord permits it. Server owners and protected staff can be warned but are not automatically timed out.

Example setup/automod sensitivity level:normal/automod warnings enabled:true/automod timeouts enabled:true/automod timeout level:moderate duration:10m

Use /automod notifications enabled:true for owner alerts. /automod diagnostics enabled:true sends bot operators an alert containing the server, user, and a short excerpt of the flagged message. /automod log-channel sets a private fallback channel for owner notices when DMs fail. It must deny View Channel to @everyone. Run /analytics moderation period:30d to review trends.

2. Choose the AI route

Run /ai status first. If OmniCore's bot owners approved local AI for your server, mentions use local Ollama and do not need your API key. Otherwise, run /ai setup to open a private, one-use HTTPS setup link. Connect your own provider key there; never paste a key into Discord. Provider requests can incur charges to your account.

After connecting, /ai model selects an available model. /ai vision shows image settings, lets you choose a vision-capable model, and limits images to one through three. /ai limits controls daily use and concurrency; /ai channel and /ai role restrict who can use provider AI. /ai usage shows recent request and token counts. /ai thinking controls local Ollama thinking for server text; it does not change a cloud provider's reasoning settings.

AI is optional

Moderation and server utilities still work without a connected provider. If the bot says no provider is connected, the server owner can use /ai setup; if the server is approved for local AI, use /ai status to confirm that route.

Path 02 / Member

Use OmniCore day to day

Find information

Run /help to browse commands, /serverinfo for server details, and /ping to check whether OmniCore is responding. /all and /role all list roles; /highest_role_from_member and /compare_roles help explain role order. Some commands are server-only; Discord may hide commands you cannot use.

Ask the AI

In a server with AI access, mention @OmniCore in your message or reply to one of its messages. In a server using a connected provider, /ask question:... is another way to ask. AI may be limited by channel, role, daily quota, or model availability. If you are denied access, ask the server owner to review /ai status, /ai channel, and /ai role.

Example@OmniCore Can you explain this server's event schedule?

Understand or generate images

For image recognition, attach a PNG, JPEG, WebP, or GIF to the same message as your @OmniCore question, or reply directly to the exact message containing the image and mention OmniCore. It does not search earlier unrelated messages or other channels. The limit is at most three images per request, and an owner can set a lower limit. A text-only selected model cannot analyze images.

Two valid image questions@OmniCore What is in this screenshot? [attach image][Reply directly to the image] @OmniCore What does this error mean?

Where local image generation is available, /imagegen prompt:... and /imagine prompt:... do the same thing: generate a public image from your description. Only bot-owner-approved local AI servers can use them. Use /imagegenstop to cancel your own active request; server and bot owners can stop requests they manage. Generation may queue and can fail when the local model or disk space is unavailable.

Private DMs

Your first written DM to OmniCore becomes a request to the bot owners. They see your username, ID, and a short excerpt, then approve or deny it. The first message is not sent to AI. Once approved, you can chat privately using local Ollama, run /dmaccess status, set a personal response preference with /dmaccess my_prompt, or clear it with /dmaccess clear_my_prompt. Bot-owner preferences for your account take priority. Private text chat does not keep a persistent bot conversation history.

DM image analysis has a separate restriction: only a current server owner who enabled /ai vision dm_enabled:true for their own connected provider key can use that key in DMs. Provider usage may cost money. An approved text DM alone does not enable DM images.

For moderators

Use Discord permissions deliberately

Moderation commands check the caller's Discord permissions. OmniCore also needs the matching bot permission and a role above the target for actions such as timeouts, kicks, and bans. The server owner can configure AutoMod separately; moderators do not need to run AutoMod manually for every message.

A server owner can also ask OmniCore to time out one clearly mentioned member for up to two days by mentioning the bot and specifying a duration. The bot checks the target and Discord permissions outside the AI model.

Different from a server owner

What OmniCore bot owners control

Bot owners operate OmniCore across servers. They can approve or disapprove local AI for a guild and manage private DM requests. A server owner cannot run these operator commands just because they own a Discord server.

In a private DM with OmniCore, bot owners can run /dmaccess pending, /dmaccess approve user_id:..., /dmaccess deny user_id:..., and /dmaccess owner_prompt user_id:... prompt:.... Other operator controls include /restart in a server. If you need operator approval, contact the bot team through the support page; do not post API keys or private message content in a public channel.

When something does not work

Quick fixes

I cannot see a command.

Type / and select OmniCore, then check your Discord permissions and whether the command is server-only or DM-only. A newly registered global command can take time to appear; try closing and reopening the command picker. Browse the command reference.

OmniCore says AI is unavailable.

Ask the server owner to run /ai status. The guild needs bot-owner approval for local AI or a connected provider from /ai setup. Channel or role restrictions, daily limits, an unavailable model, or a provider error can also block a request.

It did not analyze the picture above.

Attach the image to your own question or reply directly to the exact image message. OmniCore never searches earlier unrelated messages. Check the format and image count, and ask the owner whether the selected model supports vision.

AutoMod warned someone but did not time them out.

The first confirmed violation is a warning. A later confirmed violation within 24 hours can time out an eligible member only when timeouts are enabled and the bot has Moderate Members permission with a higher role. Server owners and protected staff are not automatically timed out. Ask the owner to check /automod status.

Image generation failed or stopped.

The local image model, queue, memory, or host disk guard may be unavailable. Image generation requires bot-owner-approved local AI and at least 10 GiB of free internal disk space on this installation. Try again later or ask an operator to check the service; do not repeatedly submit the same job.

Still stuck? Visit Support and include the command name, server, and approximate time. Never share a bot token or API key.

Your data

Know what OmniCore sees

Server AI chats are retained for a limited period so OmniCore can answer with recent context. Explicit image questions send only the attached or directly replied-to images for that request; image bytes are not stored in the bot's long-term memory. AutoMod alerts may include a short excerpt of a flagged message. A first private DM sends its excerpt to bot owners for approval; approved private text chat is stateless in the bot.

Use /delete_my_data for your linked AI turns and DM access record. Server administrators can use /delete_memory for server AI history. Read the Privacy Policy for exact retention, provider sharing, and deletion limits.
