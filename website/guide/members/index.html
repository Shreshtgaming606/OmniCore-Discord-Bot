Guidebook/For members

Use OmniCore as a member

Start with a question, use an image, or try a slash command. AI features depend on your server’s settings.

Get started

Type / in a Discord channel and select OmniCore to see commands you can use. Start with /help for the in-Discord list, /ping to check the bot, or /serverinfo for server details.

Where can I use AI?

Your server needs bot-owner approval for local AI or a provider connected by the server owner. Channel, role, and daily limits may also apply.

Ask the AI

  1. Mention OmniCoreWrite your question in an allowed server channel and mention @OmniCore.
  2. Try a slash commandIf the server uses a connected provider, /ask lets you enter a question in Discord’s command form.
  3. Check access if it failsAsk the server owner to check /ai status, channels, roles, and usage limits.
Example message@OmniCore Can you summarize the rules for new members?

Understand an image

Give the bot the exact image you want analyzed. There are two supported ways:

  1. Attach it to your questionUpload the image in the same message where you mention OmniCore.
  2. Reply to the image messageReply directly to the message containing the image, then mention OmniCore in that reply.
Example@OmniCore What does this screenshot show? [attach image][Direct reply to an image] @OmniCore What is in this photo?
Images above are not searched

OmniCore does not look through previous unrelated messages or other channels. Attach the image or reply to it directly each time.

PNG, JPEG, WebP, and GIF attachments are supported. A request can include up to three images, or fewer if the owner sets a lower limit. The selected AI model must support vision.

Generate an image

In a server approved for local image generation, run /imagine or /imagegen and enter your prompt. Both commands do the same thing. The result is posted publicly in the channel.

Example slash command/imagine prompt:a sunset over a mountain lake

Use /imagegenstop to cancel your active request. Generation can queue and may fail if the local model or required disk space is unavailable.

Message OmniCore privately

  1. Send a written DMYour first message becomes an access request. Bot owners receive your username, ID, and a short excerpt. That message is not sent to AI.
  2. Wait for approvalAfter approval, you can chat privately with the local model. Use /dmaccess status to check access.
  3. Adjust your replies/dmaccess my_prompt sets a personal preference; /dmaccess clear_my_prompt removes it. Bot-owner instructions for your account take priority.

DM image analysis is separate. It requires a current server owner to enable DM vision with their own connected provider key. Approval for text DMs alone does not enable DM images.
