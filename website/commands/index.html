/automodView and configure automatic safety moderation. One warning, then timeout on another confirmed violation within 24 hours.Server owner for changes+
CategoryModeration
Who can use itAnyone can view; only the server owner can change settings
WhereServer only
Bot permissionModerate Members for automatic timeouts

Subcommands

status / settings

Show the current policy.

enable / disable

Turn AutoMod on or off.

sensitivity / timeout

Choose low, normal, or high and set durations up to two days.

warnings / timeouts / notifications

Control each behavior.

log-channel

Set a private fallback for owner notifications.
