What OmniCore provides

OmniCore provides Discord moderation commands, server utilities, and an assistant that responds in servers approved for AI use. Features may change, be unavailable, or be removed as the project develops. Server owners can use a secure web pairing page to connect their own AI provider account. OmniCore has no paid subscription.

You must be eligible to use Discord and have authority to install an app or use a command in the server where you act. Server owners and administrators are responsible for deciding which roles may use OmniCore, reviewing its requested permissions, and informing members about the bot's use where appropriate.

Moderation commands use Discord permissions and role hierarchy. If AI is approved for a server, the assistant may use a timeout tool for the member who triggered an interaction when the bot has permission. Administrators should account for that behavior before asking for AI approval.
