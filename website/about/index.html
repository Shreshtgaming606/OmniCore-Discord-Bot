About OmniCore

A practical bot for people running communities.

OmniCore focuses on the tools that help a server stay organized, responsive, and easier to manage.

Why it exists

Running a Discord server is a steady stream of small decisions. OmniCore puts moderation and useful server information close to the conversation, with an optional AI layer for approved communities.

The bot is developed by Shresht Hiremath and Arnay Kumar. It is an independent project and is not affiliated with Discord.

What powers it

Rust + PoiseDiscord commands and gateway events
MongoDBServer settings, lock records, and AI history
OllamaAI responses for approved servers
WikipediaArticle lookup when the assistant calls those tools
