Why these permissions are requested

OmniCore asks for capabilities its current commands use. Server role hierarchy and channel overrides still apply.

Read and reply

View channels, send messages, send in threads, embed links, and read message history for responses and message operations.

Moderate members

Kick, ban, and timeout members when an authorized command or the approved AI timeout tool is used.

Manage server content

Manage messages for purge; manage channels and roles for lock and unlock; create an invite for an operator-only command.

The bot requests Message Content and Guild Members privileged gateway intents for text commands, AI mentions, and member-based moderation.
